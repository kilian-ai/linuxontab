How it got to you: web view panel → page-side HTTP client → injected TCP connection into the guest NIC → 192.168.86.100:8080 → nginx accept4(), epoll_wait(), writev() → back out the same way. Every syscall in that chain ran on the wasm kernel.

Config: /etc/nginx/nginx.conf · logs: /var/log/nginx/ · stop: nginx -s stop · the Apache demo is httpd-demo on port 8081.
