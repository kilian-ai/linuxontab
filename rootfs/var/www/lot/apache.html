How it got to you: web view panel → page-side HTTP client → injected TCP connection into the guest NIC → 192.168.86.100:8081 → httpd accept(), poll(), writev() → back out the same way. Every syscall in that chain ran on the wasm kernel.

Config: /etc/httpd/httpd.conf · logs: /var/log/httpd/ · stop: httpd -k stop · the nginx demo is nginx-demo on port 8080.
