_$ Packages

Software you can install in a LinuxOnTab tab. Every package is compiled to WebAssembly and runs on the real Linux kernel in your browser; nothing is installed on your computer.

In the shellapk browse to pick from a list, or apk search <word> then apk add <name>.
On the X desktopApps → Install Software. Apps you haven't installed yet install themselves when you open them.
Straight from here"Try it" opens a fresh tab with that package already installed.
    Generated live from index.json, the same index apk uses. Missing something? Open an issue.
